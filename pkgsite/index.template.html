OPNsense IPsec WatchDog

pkg repository — not a webpage for browsing, just a place pkg fetches from.

Two FreeBSD bases are published — OPNsense's own base OS moves to a new FreeBSD major version every so often, and a pkg package is tagged for one specific base. Run pkg config abi on your box first to see which one you have, then use the matching section below.

FreeBSD 15 (OPNsense 26.7 and newer)

On the OPNsense box. Uses printf rather than a heredoc since OPNsense's default root shell is csh, which doesn't understand << 'EOF' heredoc syntax at all — it just hangs waiting for input if you paste one in:

printf '%s\n' \
  'ipsecwatchdog: {' \
  '  url: "https://nerexbcd.github.io/OPNSense-IPSec-WatchDog/",' \
  '  enabled: yes' \
  '}' \
  > /usr/local/etc/pkg/repos/ipsecwatchdog.conf
pkg update
pkg install ipsec-watchdog

Already installed? pkg update && pkg upgrade ipsec-watchdog picks up new releases.

Or grab it directly:

    __FILE_ROWS_15__

FreeBSD 14 (older OPNsense, e.g. 25.1–26.1.x)

Same idea, different repo URL:

printf '%s\n' \
  'ipsecwatchdog: {' \
  '  url: "https://nerexbcd.github.io/OPNSense-IPSec-WatchDog/freebsd14-amd64/",' \
  '  enabled: yes' \
  '}' \
  > /usr/local/etc/pkg/repos/ipsecwatchdog.conf
pkg update
pkg install ipsec-watchdog

Or grab it directly:

    __FILE_ROWS_14__
